{% comment %} Área de evidências fotográficas — envio de quantas fotos forem necessárias, cada uma marcada como Antes, Depois ou valendo para os dois momentos. Espera no contexto: execucao (opcional) — quando presente, lista as fotos já gravadas com opção de remover (checkbox escondido em `remover_fotos`). fotos_existentes (opcional) — lista de PreventivaFoto já na execução. O formulário que inclui este bloco PRECISA ter enctype="multipart/form-data". Contrato com o servidor (ver services/preventiva_fotos_service.coletar_do_request): - `fotos` → um input file múltiplo; cada arquivo selecionado vira um item. - `momentos` → um hidden POR ARQUIVO, na MESMA ORDEM dos arquivos. - `remover_fotos` → ids das fotos existentes marcadas para exclusão. A ordem é o único vínculo entre arquivo e momento — por isso o JS reconstrói a lista de arquivos via DataTransfer sempre que algo muda, mantendo os hidden em sincronia. Sem JS, os arquivos ainda sobem e caem no padrão "antes" no servidor. {% endcomment %}
