{% comment %} Card "Etapas para concluir" — o que falta para a contratação poder ser CONCLUÍDA. A vaga "Preenchida" quer dizer que o RH encontrou a pessoa; "Concluída" quer dizer que o colaborador foi cadastrado, recebeu a estrutura e foi integrado. Cada etapa é DEDUZIDA do que o sistema já sabe (colaborador cadastrado, reserva, entrega por movimentação, acesso provisionado, chamado concluído) — por isso não há caixa para marcar à mão o que o sistema consegue provar. Só duas coisas pedem decisão humana: DISPENSAR uma etapa que não se aplica (com justificativa, só o TI) e registrar as orientações de uso. A trava de conclusão é do service (`contratacao_service.concluir`), não deste card. Três situações, lidas separadas: a da VAGA, a da INTEGRAÇÃO e a dos CHAMADOS de TI. {% endcomment %} {% if obj.status != 'cancelada' %}
